===============================================================
文件功能说明
===============================================================

🌟 核心文件：
1. main.ts - Vue 应用入口，初始化 Pinia、Element Plus、路由等
2. App.vue - 根组件，包含全局路由守卫和样式
3. env.d.ts - 环境变量类型定义

🔧 服务层文件：
1. api.ts - 封装所有 HTTP API 调用，包含拦截器和错误处理
2. websocket.ts - WebSocket 服务，处理实时通信
3. sse.ts - SSE 服务，处理服务器推送事件
4. audio.ts - 音频服务，处理录音、播放和音频处理

📊 状态管理：
1. store/index.ts - Pinia store，包含用户状态和面试状态管理

🎨 样式文件：
1. styles/index.scss - 全局样式和工具类
2. styles/variables.scss - 样式变量，支持暗黑模式

📱 页面组件：
1. Login.vue - 登录页面，支持注册和演示账号
2. MainLayout.vue - 主布局，包含导航栏和底部信息
3. Interview.vue - AI面试页面，支持文本/语音输入，实时对话
4. History.vue - 面试历史页面，统计数据和详细记录
5. Report.vue - 面试报告页面，ECharts 可视化和详细分析
6. Profile.vue - 个人中心页面，用户设置和安全管理

🛠️ 工具文件：
1. utils/index.ts - 常用工具函数集合
2. types/index.ts - TypeScript 类型定义
3. config/index.ts - 应用配置文件
4. mock/interviews.ts - 模拟数据生成器

===============================================================
技术栈说明
===============================================================

🚀 前端框架：
- Vue 3.4.0+：渐进式 JavaScript 框架
- TypeScript 5.4.0+：类型安全的 JavaScript 超集
- Vite 5.0.0+：下一代前端构建工具

🔧 状态管理：
- Pinia 2.1.7+：Vue 官方推荐的状态管理库

🎨 UI 组件库：
- Element Plus 2.5.0+：基于 Vue 3 的组件库
- Element Plus Icons：图标组件库

📊 数据可视化：
- ECharts 5.5.0+：强大的图表库
- vue-echarts 6.6.0+：Vue 3 的 ECharts 包装器

🌐 网络通信：
- Axios 1.6.0+：HTTP 客户端
- WebSocket：实时双向通信
- SSE (Server-Sent Events)：服务器推送事件

🔊 音频处理：
- Web Audio API：音频录制和播放
- MediaRecorder API：音频录制

🔌 工具库：
- mitt 3.0.0+：事件总线
- sass 1.69.5+：CSS 预处理器

===============================================================
开发指南
===============================================================

1. 📦 安装依赖：
   npm install 或 yarn install 或 pnpm install

2. 🔧 环境配置：
   复制 .env.example 为 .env，并配置环境变量

3. 🚀 启动开发：
   npm run dev

4. 📦 构建生产：
   npm run build

5. 📖 代码规范：
   npm run lint       # 代码检查
   npm run format     # 代码格式化
